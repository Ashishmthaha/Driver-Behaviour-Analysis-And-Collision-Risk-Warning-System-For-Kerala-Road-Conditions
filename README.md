# Driver-Behaviour-Analysis-And-Collision-Risk-Warning-System-For-Kerala-Road-Conditions

## Description
An AI/ML-based system that analyzes driver behaviour and
classifies collision risk under Kerala road conditions.

## Technologies
- Python
- Artificial Intelligence/Machine Learning (AI/ML)
- Random Forest
- SUMO
- NATPAC dataset

## Key Features
- Vehicle behaviour feature extraction
- Collision-risk classification
- Traffic simulation using SUMO
- Low, Medium, and High risk warnings

## How It Works
NATPAC vehicle telemetry is preprocessed and behavioural
features are extracted. A Random Forest model classifies
the collision risk, which is integrated with SUMO-based
traffic simulation.

## Project Status
Academic project.
